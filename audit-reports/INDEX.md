# Audit Reports — Index

161 audit artefacts have accumulated over ~20 review rounds. Not all
are current. This index groups them by purpose so future readers can
find what's authoritative without grepping the whole directory.

**Rule of thumb**: if a master summary (`00-*.md`) and a persona /
round file disagree, the master summary wins. Persona / round files
are historical snapshots; master summaries are the distilled current
position.

## How to use this index

- **New to the repo?** Start with `00-MASTER-SUMMARY.md` and
  `00-live-flip-readiness.md`. These give you the current state.
- **Investigating a bug?** Check the domain audit for the matching
  area (`backend`, `frontend`, `security`, etc.) and the highest-
  numbered persona sweep — later sweeps include fixes from earlier
  rounds.
- **Working on a strategy?** Start with `expert-<name>.md` for the
  qualitative review, then `phase1-<name>.md` + the OOS JSON for the
  quantitative picture.
- **If a persona claim contradicts a master summary**, trust the
  master summary; persona files were point-in-time snapshots.
