TopBar Redesign

Current bar has 9 elements in one row: logo, nav tabs, LIVE dot, search, P&L, broker, mode badge, alerts, settings. Which approach reduces clutter?

A

Two-Row Header

Row 1: Logo + Nav tabs + Search bar (centered, wider) + Alerts + Settings

Row 2 (slim data strip): P&L | Broker status | Mode badge | LIVE indicator — all in a 28px accent bar below

Pro: Clean separation of navigation vs. status. Search gets more room. Con: Uses ~76px total height instead of 48px.

B

Collapsible Single Row

Always visible: Logo + Nav tabs + Search + P&L + Alerts

On hover/click: Broker, Mode, Settings slide out from a "⋯" menu on the right

Pro: Keeps 48px height, less visual noise. Con: Hides broker/mode status — might miss context.

C

Keep Single Row, Regroup

Left: Logo + Nav tabs

Center: Search bar (wider)

Right: Compact P&L chip | LIVE dot | Alerts bell | Profile avatar (click opens: broker, mode, settings, shortcuts)

Pro: Stays 48px, groups related items behind a profile menu. Con: Broker/mode requires one extra click.
